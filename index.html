06 // TECHNICAL DUE DILIGENCE

Frequently Asked Questions

Can't client-side license validation be bypassed in browser extensions?

Yes — let's be completely honest about this. Because extension JavaScript runs locally in the user's browser, a determined developer can always inspect DevTools, patch the unpacked bundle, or mock a network response to unlock local UI features. Zero-backend validation is an intentional engineering tradeoff for $5–$29 local utility extensions where your marginal cost per user is $0: you avoid paying monthly server bills, and most paying users won't spend time patching and reloading an unpacked extension to bypass a modest one-time tool. If your extension proxies paid server resources (like LLM API keys or proprietary data), you should validate the Polar license key on your backend before serving those API calls.

Do I need to run a backend server or database?

No. Polar.sh exposes public Customer Portal endpoints for activating, validating, and deactivating license keys using only your public Organization ID. Your extension talks directly to Polar.sh without exposing secret API tokens.

Why Polar.sh instead of Lemon Squeezy or Stripe?

Lemon Squeezy is sunsetting transaction and license processing on March 31, 2027, while raw Stripe leaves global VAT/sales tax compliance on your shoulders and isn't available in many regions. Polar.sh acts as Merchant of Record, natively issues license keys, auto-grants file downloads and private GitHub access, and pays out globally (including Taiwan).

Does it work with Cursor, Claude Code, and Firefox?

Yes. PolarExt ships with AGENTS.md, CLAUDE.md, and .cursor/rules/polarext-mv3.mdc so AI coding assistants follow MV3 CSP and Polar API rules automatically. Run npm run build:firefox anytime to emit a Firefox MV3 bundle with sidebar_action and browser_specific_settings.gecko.

What happens when a customer loses internet connection?

PolarExt caches verified state in chrome.storage.local and grants a configurable 72-hour offline grace period (with backwards-clock tamper protection) if Polar.sh is temporarily unreachable. Once connectivity returns, daily chrome.alarms silently revalidate the key.

Can I strip out the SEO & Link Inspector and build my own extension?

Yes. The included SEO & Link Inspector is a working, store-ready product so you can test Popup, Side Panel, Context Menus, Scan History, Daily Free Quota, and Pro gating on day one. Replace seo-audit.ts with your own domain logic while keeping the licensing, storage, setup CLI, and CWS packaging pipeline intact.

How is the starter kit delivered after checkout?

Immediately after checkout on Polar.sh, you receive an automatic download of the complete clean source archive (polarext-starter-kit-v1.2.0-source.zip) plus access to the private GitHub repository.
